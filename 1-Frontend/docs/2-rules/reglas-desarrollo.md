# Reglas de Desarrollo — Qaway Lab

Este documento contiene las reglas de desarrollo y comportamiento técnico del asistente de Inteligencia Artificial para el proyecto Qaway Lab.

## 1. Flujo de Trabajo y Git
- Antes de iniciar cualquier modificación, el asistente debe verificar el estado del repositorio (`git status`, `git diff`) para asegurar que no haya conflictos pendientes.
- El código se desarrollará con la máxima consistencia visual siguiendo el sistema de diseño oficial de Qaway Lab (Amarillo `#FFD200` como acento).
