# Qaway Mascota React

Demo de una mascota interactiva construida como componente React.

## Tecnologías
- React
- Vite
- SVG vectorial
- Motion for React

## Ejecutar

```bash
npm install
npm run dev
```

Luego abre la URL que indique Vite.

## Qué demuestra

El botón cambia el estado del componente:

NORMAL → FELIZ → NORMAL

La transición modifica ojos, boca, cabeza, brazos, cola, cuerpo y partículas. La mascota es SVG, por lo que no depende de un PNG animado.
