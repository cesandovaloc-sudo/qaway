# 4.1 · Paso 0 — Verificar el terreno antes de crear nada

Antes de la primera tabla hay que confirmar **3 cosas**, porque las tablas nuevas van a apuntar a
ellas con claves foráneas:

1. Que exista `public.tenants` (la empresa).
2. Que exista `public.users` (la cuenta; `gp_personas.user_id` la referencia).
3. Que exista `public.gestor_unidades` (la jerarquía organizacional; `gp_nodos_edt.sede_unidad_id`
   y `gp_proyecto_unidades_r.unidad_id` la referencian).

Si alguna falta, el `CREATE TABLE` de `0002` fallará con *relation does not exist* y no es un error
del diseño: es que falta una migración de plataforma.

---

## Consulta de verificación

Pegar en **SQL Editor → Run**:

```sql
-- ¿Existen las 3 tablas de plataforma que vamos a referenciar?
select
  t.nombre                                    as tabla_requerida,
  (c.oid is not null)                         as existe,
  coalesce(c.reltuples::bigint, 0)             as filas_aprox
from (values
  ('public.tenants'),
  ('public.users'),
  ('public.gestor_unidades'),
  ('public.user_app_roles'),
  ('public.app_catalog'),
  ('public.tenant_app_subscriptions')
) as t(nombre)
left join pg_class c
  on c.oid = to_regclass(t.nombre);
```

### Qué debe salir

| tabla_requerida | existe | para qué la usamos |
|---|---|---|
| `public.tenants` | `true` | `empresa_id` de proyectos, personas, fases… |
| `public.users` | `true` | `gp_personas.user_id` |
| `public.gestor_unidades` | `true` | sede/unidad de nodos EDT y alcance del proyecto |
| `public.user_app_roles` | `true` | la RLS decide el acceso a la app (etapa 0004) |
| `public.app_catalog` | `true` | el slug de la app |
| `public.tenant_app_subscriptions` | `true` | el plan contratado |

Con las **3 primeras** en `true` ya podemos crear tablas. Las 3 últimas solo se necesitan cuando
lleguemos al bloque de RLS (documento 0004), pero conviene saberlo desde ahora.

## Verificación extra (opcional, pero útil para el curso)

```sql
-- ¿Ya hay tablas gp_* de un intento anterior? Debe salir 0 filas si partimos de cero.
select tablename
from pg_tables
where schemaname = 'public' and tablename like 'gp\_%'
order by tablename;
```

- **0 filas** → partimos de cero, perfecto.
- **Algunas filas** → dime cuáles antes de crear; puede haber un intento previo a medio hacer.
