# Arquitectura Saniclick

## Tipo
Sitio one-page público.

## Estructura
Hero → categorías → servicios → banners → trabajos realizados → calidad → testimonios/proyecto → FAQ → CTA → footer.

## Criterios
- Contenido separado en `src/data`.
- Componentes visuales en `src/components`.
- Iconos centralizados.
- Animación de UI con Motion.
- Reveal por IntersectionObserver.
- Imágenes locales.
- Sin acceso directo a backend desde componentes visuales.
