# CoraVet Web — V4

Sitio multipágina en React + TypeScript + Vite + Tailwind CSS 4 + React Router + Lucide.

## Rutas
- / — Inicio
- /veterinaria — Servicios
- /uvivet — UviVet
- /equipo — Equipo
- /pet-shop — Pet Shop
- /blog — Blog
- /contacto — Contacto
- /reservar-cita — Reserva

## Instalación
npm install
npm run dev

## Validación
npm run typecheck
npm run build
npm run lint

La arquitectura sigue el Estándar general para proyectos web Qaway V4: TypeScript estricto, Tailwind 4, componentes reutilizables, rutas independientes, responsive mobile-first y separación entre UI y contenido. Las fotografías son placeholders remotos y deben sustituirse por los assets finales de CoraVet.
