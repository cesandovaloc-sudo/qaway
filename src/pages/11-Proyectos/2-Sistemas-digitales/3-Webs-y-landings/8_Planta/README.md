# Plantora — Responsive Ecommerce Concept

Concepto original inspirado en la lógica UX de una tienda de plantas, pero sin reproducir la composición visual de la referencia.

## Secciones incluidas
1. Header + navegación + búsqueda + carrito
2. Hero con formas orgánicas integradas al fondo
3. Barra de confianza
4. Explorar por categorías
5. Productos recomendados
6. Producto destacado
7. Guía para elegir planta
8. Historia / propuesta de marca
9. Reseñas
10. Preguntas frecuentes
11. Newsletter
12. Footer

## Interacciones demo
- Menú responsive.
- Contador de carrito.
- Añadir productos al carrito.
- FAQ desplegable.
- Navegación por anclas.

## Imágenes
Las fotografías del demo usan URLs de imágenes de Unsplash para facilitar la prueba visual. Para producción conviene reemplazarlas por fotografías propias o un banco/licencia controlada.

## Ejecutar
npm install
npm run dev

Luego abrir la URL que entregue Vite.
