# Vallet — Asesoría Inmobiliaria

Landing one-page construida con React + TypeScript + Vite + Tailwind CSS 4, siguiendo las referencias visuales proporcionadas en este proyecto.

## Desarrollo

```bash
npm install
npm run dev
```

## Validación

```bash
npm run typecheck
npm run lint
npm run build
```

## Estructura visual

- Hero de alto impacto con formulario de asesoría.
- Beneficios y propuesta de valor.
- Propiedades destacadas.
- Proceso de asesoría.
- Resultados que respaldan la experiencia.
- Testimonios.
- CTA de contacto.
- Formulario de consulta ampliado.
- Información importante.
- Footer institucional.

Las imágenes usadas en esta primera implementación son recortes de las referencias visuales proporcionadas para conservar la dirección estética y el contenido de demostración.
