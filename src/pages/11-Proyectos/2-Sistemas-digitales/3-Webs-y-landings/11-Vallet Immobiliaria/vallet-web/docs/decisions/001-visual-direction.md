# Dirección visual inicial

## Base

La implementación toma como referencia directa las tres imágenes proporcionadas en la conversación para Vallet Asesoría Inmobiliaria.

## Decisiones

- Paleta principal: teal oscuro, blanco cálido y naranja de acento de la marca.
- Titulares editoriales con serif de alto contraste.
- Texto funcional con sans serif limpia.
- Cards de propiedades sobre fondo teal.
- Formularios con superficies claras u oscuras según sección.
- Padding amplio entre secciones para evitar sensación de interfaz comprimida.
- Landing orientada a asesoría, compra, venta y alquiler; no se presenta como inmobiliaria genérica.
