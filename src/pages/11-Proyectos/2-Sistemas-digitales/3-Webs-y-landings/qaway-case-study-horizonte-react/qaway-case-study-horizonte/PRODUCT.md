# PRODUCT.md — Horizonte Inmobiliaria Case Study

## Objetivo
Presentar un proyecto web como una experiencia editorial/portfolio de alto impacto, no como otra página web comercial.

## Público
Clientes potenciales de Qaway Lab que evalúan capacidad estratégica, visual y técnica.

## Conversión
CTA final: hablar sobre un proyecto similar.

## Principios
- Experiencia predominantemente visual.
- Explicaciones breves y con flujo.
- Alternancia de superficies: fotografía, color de marca y papel.
- Secciones visual-only cuando el contenido ya se entiende mediante mockups.
- Dos espacios de video.
- La identidad visual pertenece al proyecto mostrado, no a Qaway.

## Proyecto demo
Horizonte Inmobiliaria.
