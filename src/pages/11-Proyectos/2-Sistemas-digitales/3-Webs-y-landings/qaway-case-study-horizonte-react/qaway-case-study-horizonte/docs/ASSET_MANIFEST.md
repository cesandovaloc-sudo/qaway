# Asset manifest

Los SVG incluidos son **fallback visuales locales** para que el proyecto funcione sin depender de URLs externas.

Sustituir por assets finales:

- hero-building.svg → fotografía/clip del proyecto inmobiliario.
- interior-visual.svg → fotografía full-bleed de interior/arquitectura.
- interaction-visual.svg → poster del segundo video.
- closing-visual.svg → fotografía de cierre.
- stationery.svg, cards.svg, folder.svg, signage.svg → mockups finales de identidad.
- Los mockups de navegador/móvil se generan con React/CSS para mantener el sistema editable.

Los dos PNG de `public/references/` son referencias entregadas por el usuario y no deben publicarse como parte del sitio final.
