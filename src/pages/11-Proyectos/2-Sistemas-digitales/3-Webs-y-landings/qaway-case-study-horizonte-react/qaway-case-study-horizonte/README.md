# Qaway Case Study — Horizonte Inmobiliaria

Implementación base de un portfolio/case study visual en React + TypeScript.

## Inicio

```bash
npm install
npm run dev
```

Puerto sugerido: `4170`.

## Estructura
- `src/main.tsx` → composición de la experiencia.
- `src/data/project.ts` → contenido configurable.
- `src/styles/global.css` → tokens y sistema visual.
- `public/assets` → fallback visuales locales.
- `public/references` → referencias entregadas, solo para consulta.

## Importante
Este repositorio es una base visual. Sustituir los SVG fallback por fotografías, videos y mockups finales antes de producción.
